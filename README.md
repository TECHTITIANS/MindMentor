# MindMentor
IIIT Surat Devheat Hackathon
🧠 MindMentor
MindMentor is a full-stack wellness tracking platform designed to promote mental well-being and personal growth. It offers an intuitive interface for users to log moods, gain insights through AI-powered analysis, and interact with counselors through a secure dashboard. With gamified wellness tracking, MindMentor makes mental health support more engaging, accessible, and insightful.
